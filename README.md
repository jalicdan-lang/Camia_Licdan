# Title:
Abuh (hypotenuse finder)

## Description:
This is a program that calculates the hypotenuse of a triangle

## How to run:
Click the program to open it.
Put in the length of side A and B.

## Input needed:
The unit length of side A and side B

## Sample output:
Side A = 5
Side B = 3

The length of the hypotenuse is 8
